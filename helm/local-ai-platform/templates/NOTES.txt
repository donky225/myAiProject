Local AI Platform이 네임스페이스 "{{ .Values.global.namespace }}" 에 배포되었습니다.

1) 배포 상태 확인
   kubectl get pods -n {{ .Values.global.namespace }} -w

2) 웹 UI 접속
{{- if eq .Values.springboot.service.type "NodePort" }}
   http://localhost:{{ .Values.springboot.service.nodePort }}
   (Minikube라면: minikube service springboot -n {{ .Values.global.namespace }})
{{- else }}
   kubectl port-forward -n {{ .Values.global.namespace }} svc/springboot 8080:{{ .Values.springboot.service.port }}
{{- end }}

3) Grafana 접속
{{- if eq .Values.monitoring.grafana.service.type "NodePort" }}
   http://localhost:{{ .Values.monitoring.grafana.service.nodePort }}  (계정: {{ .Values.monitoring.grafana.adminUser }} / values.yaml에 설정한 비밀번호)
{{- end }}

4) GPU 서비스(Ollama/SD/Reranker)는 이 차트에 포함되어 있지 않습니다.
   먼저 로컬에서 docker compose로 GPU 스택을 켜두세요:
     docker compose up -d ollama stable-diffusion rerank-service
   그 후 이 차트의 파드들이 {{ .Values.global.externalGpuServices.ollamaUrl }} 등으로 접근합니다.
